# JointIndex

`JointIndex(NonMax<u32>)` is a zero-based index into the containing skeleton's `joints` ([definition](Skeleton.md)).
It uses the [NonMax encoding](NonMax.md).

Requirements: [PRO-0018](../../design/requirements/protocol/PRO-0018.md), [PRO-0020](../../design/requirements/protocol/PRO-0020.md).
