# SampleDescriptorIndex

`SampleDescriptorIndex(NonMax<u32>)` is a zero-based index into `Capabilities.sample_descriptors` ([definition](Capabilities.md)).
It uses the [NonMax encoding](NonMax.md).

Requirements: [PRO-0013](../../design/requirements/protocol/PRO-0013.md), [PRO-0020](../../design/requirements/protocol/PRO-0020.md).
