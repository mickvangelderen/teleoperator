# SampleGroupIndex

`SampleGroupIndex(NonMax<u32>)` is a zero-based index into `Capabilities.sample_groups` ([definition](Capabilities.md)).
It uses the [NonMax encoding](NonMax.md).

Requirements: [PRO-0012](../../design/requirements/protocol/PRO-0012.md), [PRO-0020](../../design/requirements/protocol/PRO-0020.md).
