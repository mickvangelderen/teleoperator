# PRO-0015: Reference spaces

**Tags**: protocol

## Description

`ReferenceSpace` identifies the coordinate frame in which a pose is expressed.

| Space         | Enum value | Semantics                                                                                                           |
| ------------- | ---------- | ------------------------------------------------------------------------------------------------------------------- |
| invalid       | `0x00`     | Never valid.                                                                                                        |
| `view`        | `0x01`     | Origin and orientation follow the primary viewer's view frame, using the centroid of the view origins for stereo.   |
| `local`       | `0x02`     | World-locked, gravity-aligned frame with an origin and initial heading established by the runtime.                  |
| `stage`       | `0x03`     | Origin at the floor centre of the runtime-defined rectangular play area.                                            |
| `local_floor` | `0x04`     | Same orientation and horizontal origin as `local`, with the vertical origin at the runtime's estimated floor level. |
| `parent`      | `0x05`     | Parent joint's corresponding pose frame, resolved through the skeleton mapping ([PRO-0018](./PRO-0018.md)).         |
| reserved      | *          | Reserved for future use.                                                                                            |

## Rationale

Some sample data, like controller poses and body joints, need to establish a frame of reference before they can be interpreted correctly.

The world and view space definitions follow the core OpenXR reference spaces:

- [VIEW](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_REFERENCE_SPACE_TYPE_VIEW.html),
- [LOCAL](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_REFERENCE_SPACE_TYPE_LOCAL.html),
- [STAGE](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_REFERENCE_SPACE_TYPE_STAGE.html),
- [LOCAL_FLOOR](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_REFERENCE_SPACE_TYPE_LOCAL_FLOOR.html).
