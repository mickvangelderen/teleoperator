# PRO-0013: Sample descriptors

**Tags:** protocol

A sample descriptor identifies an individually addressable source of tracking data and specifies its semantic kind, supported encoding formats, and sample group.

| Field               | Description                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------- |
| `id`                | A device-stable unique identifier. Use an OpenXR interaction profile component path where applicable.         |
| `name`              | Human-readable name provided by the device                                                                    |
| `description`       | Human-readable description provided by the device                                                             |
| `kind`              | Semantic kind of the sample, as defined by [PRO-0011: Sample kinds](./PRO-0011.md)                            |
| `supported_formats` | Non-empty list of supported encoding formats, as defined by [PRO-0010: Sample formats](./PRO-0010.md)         |
| `group`             | Index of the sample group to which the sample belongs, as defined by [PRO-0012: Sample groups](./PRO-0012.md) |
