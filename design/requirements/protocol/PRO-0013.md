# PRO-0013: Sample descriptors

**Tags**: protocol

A `SampleDescriptor` describes one individually addressable source of tracking data that a client can select for a subscription.
It identifies the source, the semantic meaning of its values, and the supported representations of those values.

| Field               | Description                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                | A device-stable unique identifier. Use an OpenXR interaction profile component path when the source corresponds to such a component. |
| `name`              | Human-readable name provided by the device.                                                                                          |
| `description`       | Human-readable description provided by the device.                                                                                   |
| `kind`              | Semantic kind of the sample ([PRO-0011](./PRO-0011.md)).                                                                             |
| `supported_formats` | Non-empty list of supported encoding formats ([PRO-0010](./PRO-0010.md)).                                                            |
| `group`             | Index of the sample group in the advertised `Capabilities.sample_groups` list ([PRO-0016](./PRO-0016.md)).                           |
| Kind-specific data  | Additional descriptor data selected by the `kind` tag.                                                                               |

For `kind == pose`, kind-specific data contains:

| Field              | Description                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| `supported_spaces` | Non-empty list of reference spaces in which poses can be provided ([PRO-0015](./PRO-0015.md)). |
