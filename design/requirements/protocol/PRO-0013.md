# PRO-0013: Sample descriptors

**Tags**: protocol

## Description

### SampleDescriptor

A `SampleDescriptor` describes one individually addressable source of tracking data that a client can select for a subscription.
It identifies the source, the semantic meaning of its values, and the supported representations of those values.

| Field               | Description                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                | A device-stable unique identifier.                                                                                                   |
| `name`              | Human-readable name provided by the device.                                                                                          |
| `description`       | Human-readable description provided by the device.                                                                                   |
| `kind`              | Semantic kind of the sample ([PRO-0011](./PRO-0011.md)).                                                                             |
| `supported_formats` | Non-empty list of supported encoding formats ([PRO-0010](./PRO-0010.md)).                                                            |
| `group`             | `SampleGroupIndex` of the acquisition group ([PRO-0012](./PRO-0012.md)).                                                             |
| Kind-specific data  | Additional descriptor data selected by the `kind` tag.                                                                               |

For `id`, use an OpenXR interaction profile component path when the source corresponds to such a component.

#### `kind == pressed`

| Field                  | Type                            | Description                                            |
| ---------------------- | ------------------------------- | ------------------------------------------------------ |
| `press_count_sample`   | `Option<SampleDescriptorIndex>` | Press-edge counter (`press_count`) for this input.     |
| `release_count_sample` | `Option<SampleDescriptorIndex>` | Release-edge counter (`release_count`) for this input. |

#### `kind == touched`

| Field                  | Type                            | Description                                            |
| ---------------------- | ------------------------------- | ------------------------------------------------------ |
| `touch_count_sample`   | `Option<SampleDescriptorIndex>` | Touch-edge counter (`touch_count`) for this input.     |
| `untouch_count_sample` | `Option<SampleDescriptorIndex>` | Untouch-edge counter (`untouch_count`) for this input. |

#### `kind == pose`

| Field                        | Type                            | Description                                                                                    |
| ---------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------- |
| `supported_spaces`           | `list<ReferenceSpace>`          | Non-empty list of reference spaces in which poses can be provided ([PRO-0015](./PRO-0015.md)). |
| `position_valid_sample`      | `Option<SampleDescriptorIndex>` | `position_valid` sample for this pose.                                                         |
| `orientation_valid_sample`   | `Option<SampleDescriptorIndex>` | `orientation_valid` sample for this pose.                                                      |
| `position_tracked_sample`    | `Option<SampleDescriptorIndex>` | `position_tracked` sample for this pose.                                                       |
| `orientation_tracked_sample` | `Option<SampleDescriptorIndex>` | `orientation_tracked` sample for this pose.                                                    |
| `confidence_sample`          | `Option<SampleDescriptorIndex>` | `confidence` sample applicable to this pose.                                                   |

#### `kind == revision`

| Field         | Type               | Description                          |
| ------------- | ------------------ | ------------------------------------ |
| `revision_of` | `SampleGroupIndex` | Group whose data is being versioned. |

### SampleDescriptorIndex

`SampleDescriptorIndex(NonMax<u32>)` ([PRO-0020](./PRO-0020.md)) is a zero-based index into `Capabilities.sample_descriptors` ([PRO-0016](./PRO-0016.md)).
