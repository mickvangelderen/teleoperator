# PRO-0024: Subscriptions

**Tags**: protocol

## Description

A subscription is a request for samples from a single sample group.

The subscription id is chosen by the client and may for example serve both as an identifier and as a revision.

The client can change `interval`, `phase` and `prediction_offset` while the subscription is live ([PRO-0026](./PRO-0026.md)).
Other fields are require recreating the subscription because they change the layout of the sample publication.

The messages defined below use the reliable channel ([PRO-0002](./PRO-0002.md)).

The server may reject a subscription request and should explain why.

Upon acceptance of a subscription, the server should immediately initiate publishing, without waiting for client acknowledgement.

A subscription cannot outlive its connection.

The server can terminate a subscription for any reason.

### Subscribe

Client-to-server request to create or fully replace a subscription.

| Field                    | Type                           | Description                                                                                                                                                                                                                                                         |
| ------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `subscription_id`        | `u32`                          | Client-chosen subscription id.                                                                                                                                                                                                                                      |
| `group`                  | `SampleGroupIndex`             | Acquisition group containing every selected sample ([PRO-0012](./PRO-0012.md)).                                                                                                                                                                                     |
| `channel`                | `Channel`                      | Publication channel ([PRO-0019](./PRO-0019.md)).                                                                                                                                                                                                                    |
| `interval`               | `Duration`                     | Positive interval between scheduled publication slots. A slot sends no publication when bundle 0 is empty and no on-change bundle is pending.                                                                                                                       |
| `phase`                  | `Duration`                     | Phase relative to the server clock origin, interpreted modulo `interval` ([PRO-0027](./PRO-0027.md)).                                                                                                                                                               |
| `prediction_offset`      | `Duration`                     | Desired sample prediction offset relative to scheduled publication time.                                                                                                                                                                                            |
| `sequence_number_format` | `Option<SequenceNumberFormat>` | Selected publication sequence representation; `None` omits sequence numbers. Required when there are bundles beyond bundle 0.                                                                                                                                       |
| `bundles`                | `list<list<SampleBinding>>`    | Non-empty ordered list of sample bundles ([PRO-0025](./PRO-0025.md)); bundle indices are their positions in this list. Bundle 0 is always included and may be empty; bundles 1 through N publish their latest state until acknowledged ([PRO-0028](./PRO-0028.md)). |

### SequenceNumberFormat

| Format   | Enum value | Representation          |
| -------- | ---------- | ----------------------- |
| invalid  | `0x00`     | Never valid             |
| `u16`    | `0x01`     | `Wrapping<u16>`         |
| `u32`    | `0x02`     | `Wrapping<u32>`         |
| `u64`    | `0x03`     | `Wrapping<u64>`         |
| reserved | *          | Reserved for future use |

### SubscriptionAccepted

Server-to-client response accepting a `Subscribe` request.

| Field             | Description                               |
| ----------------- | ----------------------------------------- |
| `subscription_id` | Id from the accepted `Subscribe` request. |

### SubscriptionRejected

Server-to-client response rejecting a `Subscribe` request.
A rejected replacement leaves the existing subscription unchanged.

| Field             | Description                                    |
| ----------------- | ---------------------------------------------- |
| `subscription_id` | Id from the rejected `Subscribe` request.      |
| `reason`          | Optional textual explanation of the rejection. |

### Unsubscribe

Client-to-server request to end a subscription.

| Field             | Description                                    |
| ----------------- | ---------------------------------------------- |
| `subscription_id` | Client-assigned id of the subscription to end. |

### Unsubscribed

Server-to-client notification that a subscription has ended.
Sent after either client-requested unsubscription or server-initiated termination.

| Field             | Description                                        |
| ----------------- | -------------------------------------------------- |
| `subscription_id` | Client-assigned id of the terminated subscription. |
| `reason`          | Textual explanation of the termination reason.     |
