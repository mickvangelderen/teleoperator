# PRO-0027: ServerInstant

**Tags**: protocol

## Description

`ServerInstant(NonMax<u64>)` represents a point on the server's monotonic clock, measured in nanoseconds from a server-defined origin.
All `ServerInstant` values within a connection use the same clock and origin.

## Rationale

It's inner type is `NonMax` ([PRO-0020](./PRO-0020.md)) to enable efficient representation of `Option<ServerInstant>`.
