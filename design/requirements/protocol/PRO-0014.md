# PRO-0014: Protocol message flow

**Tags**: protocol

## Description

The protocol message flow is as follows:

1. The client and server negotiate a protocol version ([PRO-0004](./PRO-0004.md)).
2. The server advertises device capabilities ([PRO-0016](./PRO-0016.md)).
3. The client subscribes to desired data ([PRO-0024](./PRO-0024.md)).
