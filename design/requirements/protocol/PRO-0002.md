# PRO-0002: Channels

**Tags**: protocol, transport

## Description

The protocol provides two channels:

| Channel      | Ordering  | Delivery       |
| ------------ | --------- | -------------- |
| `reliable`   | Ordered   | Guaranteed     |
| `unreliable` | Unordered | Not guaranteed |

Messages on the unreliable channel are sent without retransmission.
Messages on the unreliable channel must be independently decodable.

## Rationale

The unreliable channel is intended for time-sensitive data where only the latest value matters.
Retransmitting superseded values consumes bandwidth and can delay fresh data.
