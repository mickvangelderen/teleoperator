# PRO-0012: Sample groups

**Tags**: protocol

Tracking devices acquire sample data in device-specific groups, due to hardware or API constraints.

Each `SampleGroup` describes a collection of samples that are acquired together and specifies the maximum rate at which the group can be sampled.

| Field                | Description                                 |
| -------------------- | ------------------------------------------- |
| `max_sample_rate_hz` | Maximum acquisition frequency of the group. |

## Rationale

Tracking APIs often return multiple sample values together in a single acquisition operation.
Exposing these groups allows clients to select publication settings that reflect the device's acquisition boundaries, and allows samples acquired together to share a single acquisition timestamp.

Without explicit groups, we would need to communicate acquisition times individually or introduce another mechanism to identify which samples were acquired together.
