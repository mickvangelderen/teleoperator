# PRO-0009: acquisition groups

**Tags**: protocol

Tracking devices often query tracking data in groups.

Acquisition groups are explicitly described to clients during capability discovery.

Clients request data from zero or more acquisition groups and

Decisions about how to schedule sampling in case of (multiple) lower-than-sample-rate client publication rates are left to the server.

## Rationale

Hardware and/or APIs often provide snapshots of a bundle of tracking data at once.
Querying that snapshot is often relatively expensive.
By explicitly modeling acquisition groups servers can provide different data at different device specific rates, and clients can request only as much data as they need.


sample_group {
    max_sample_rate_hz: float
}

sample_descriptor {
    id: string
    name: string
    description: string
    kind: boolean | edge_count | axis1 | axis2 | position | orientation
    group: sample_group index
}
