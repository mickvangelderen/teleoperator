# PRO-0016: Capabilities

**Tags**: protocol

`Capabilities` describes the tracking data, publication settings, and subscription limits that a server exposes to a client.

| Field                | Description                                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------- |
| `sample_groups`      | Ordered list of advertised sample groups ([PRO-0012](../../../../../design/requirements/protocol/PRO-0012.md)). |
| `sample_descriptors` | List of advertised sample descriptors ([PRO-0013](../../../../../design/requirements/protocol/PRO-0013.md)).    |
