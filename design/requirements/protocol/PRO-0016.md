# PRO-0016: Capabilities

**Tags**: protocol

`Capabilities` describes the data that a server can expose to a client.

| Field                | Description                                                           |
| -------------------- | --------------------------------------------------------------------- |
| `sample_groups`      | Ordered list of advertised sample groups ([PRO-0012](./PRO-0012.md)). |
| `sample_descriptors` | List of advertised sample descriptors ([PRO-0013](./PRO-0013.md)).    |

## Rationale

Clients need a common discovery context to select tracking sources and publication settings, and associate selections with the correct advertised groups.
