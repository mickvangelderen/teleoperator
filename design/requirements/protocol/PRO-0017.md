# PRO-0017: Skeletons

**Tags**: protocol

## Description

A `Skeleton` associates live joint poses with their hierarchy and rest-pose sources.

| Field    | Type          | Description                                           |
| -------- | ------------- | ----------------------------------------------------- |
| `joints` | `list<Joint>` | Non-empty list of joints ([PRO-0018](./PRO-0018.md)). |
