# PRO-0019: Delivery modes

**Tags**: protocol, transport

## Description

A `DeliveryMode` selects the channel used for a subscription's publications ([PRO-0002](./PRO-0002.md)).

| Mode         | Enum value | Channel                  |
| ------------ | ---------- | ------------------------ |
| invalid      | `0x00`     | Never valid.             |
| `Unreliable` | `0x01`     | Tracking.                |
| `Reliable`   | `0x02`     | Control.                 |
| reserved     | *          | Reserved for future use. |
