# PRO-0019: Channel

**Tags**: protocol, transport

## Description

`Channel` identifies one of the protocol's channels ([PRO-0002](./PRO-0002.md)).

| Channel      | Enum value |
| ------------ | ---------- |
| invalid      | `0x00`     |
| `Unreliable` | `0x01`     |
| `Reliable`   | `0x02`     |
| reserved     | *          |
