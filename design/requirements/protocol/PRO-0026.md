# PRO-0026: Delivery schedule

**Tags**: protocol

## Description

### DeliverySchedule

`DeliverySchedule` specifies when a subscription publishes samples ([PRO-0024](./PRO-0024.md)).

| Variant    | Type                       | Description                                                           |
| ---------- | -------------------------- | --------------------------------------------------------------------- |
| `Periodic` | `DeliverySchedulePeriodic` | Publish periodically using the interval and prediction horizon below. |
| `OnChange` | No payload                 | Publish when a selected sample's value or availability changes.       |

### DeliverySchedulePeriodic

| Field                   | Type  | Description                                                              |
| ----------------------- | ----- | ------------------------------------------------------------------------ |
| `interval_ns`           | `u64` | Desired interval between publications in nanoseconds, greater than zero. |
| `prediction_horizon_ns` | `u64` | Desired prediction horizon in nanoseconds ([PRO-0022](./PRO-0022.md)).   |
