# PRO-0025: Sample selection

**Tags**: protocol

## Description

### SampleSelection

`SampleSelection` is an ordered selection of samples and their representations.

| Field     | Type                         | Description                                                        |
| --------- | ---------------------------- | ------------------------------------------------------------------ |
| `group`   | `SampleGroupIndex`           | Group containing all selected samples ([PRO-0012](./PRO-0012.md)). |
| `samples` | `list<SampleSelectionEntry>` | Selected samples in publication order.                             |

### SampleSelectionEntry

`SampleSelectionEntry` identifies one sample and its selected representation.
Kind-specific fields are determined by the referenced descriptor's `kind` ([PRO-0013](./PRO-0013.md)).

| Field        | Type                    | Description                                                              |
| ------------ | ----------------------- | ------------------------------------------------------------------------ |
| `descriptor` | `SampleDescriptorIndex` | Selected advertised sample ([PRO-0013](./PRO-0013.md)).                  |
| `format`     | `SampleFormat`          | Encoding format supported by the descriptor ([PRO-0010](./PRO-0010.md)). |

#### `kind == pose`

| Field             | Type             | Description                                                             |
| ----------------- | ---------------- | ----------------------------------------------------------------------- |
| `reference_space` | `ReferenceSpace` | Selected space supported by the descriptor ([PRO-0015](./PRO-0015.md)). |
