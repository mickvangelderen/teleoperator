# PRO-0018: Joints

**Tags**: protocol

## Description

A `Joint` references its parent and its live and rest-pose sample descriptors ([PRO-0013](./PRO-0013.md)).

| Field              | Type                    | Description                                       |
| ------------------ | ----------------------- | ------------------------------------------------- |
| `parent`           | `JointIndex`            | Parent joint; a self-reference identifies a root. |
| `pose_sample`      | `SampleDescriptorIndex` | Joint's live pose descriptor.                     |
| `rest_pose_sample` | `SampleDescriptorIndex` | Joint's rest-pose descriptor.                     |

## JointIndex

`JointIndex(NonMax<u32>)` ([PRO-0020](./PRO-0020.md)) is a zero-based index into the containing skeleton's `joints` list ([PRO-0017](./PRO-0017.md)).
