# PRO-0001: Serialized data is packed efficiently

**Tags**: protocol

The wire format should strike a balance between encoding and decoding efficiency, implementation complexity, and sustained bandwidth.

For data that can be expected to contribute to the bandwidth most, we should design a compact representation.

We generally prefer fixed-width integer encodings unless we can prove that a variable-width integer encoding would prove substantial savings considering the distribution of values that the field may occupy.

## Verification

A suite of realistic tracking data recordings should be used to evaluate the entropy of the serialized format.
