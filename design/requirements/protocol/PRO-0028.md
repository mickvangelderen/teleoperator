# PRO-0028: Sample publications

**Tags**: protocol

## Description

`SamplePublication` delivers a subscription's selected sample values over its chosen channel ([PRO-0024](./PRO-0024.md)).

| Field             | Description                                                                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `subscription_id` | Id of the subscription.                                                                                                                                                         |
| `acquired_at`     | `Instant` of the group's acquisition ([PRO-0012](./PRO-0012.md)).                                                                                                         |
| `predicted_for`   | `Instant` for the actual time represented by all predicted samples in this publication; required when predicted samples are present.                                      |
| `samples`         | Selected sample values in subscription order and representations ([PRO-0025](./PRO-0025.md)), distinguishing unavailable samples from valid values ([PRO-0006](./PRO-0006.md)). |
