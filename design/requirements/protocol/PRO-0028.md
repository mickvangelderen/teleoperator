# PRO-0028: Sample publications

**Tags**: protocol

## Description

`Publication` delivers a subscription's selected sample values over its chosen channel ([PRO-0024](./PRO-0024.md)).

| Field, in wire order | Type                             | Description                                                                                                                                    |
| -------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `subscription_id`    | `u32`                            | Subscription defining the bundles and sequence format ([PRO-0024](./PRO-0024.md)).                                                             |
| `acquired_at`        | `Instant`                        | Common acquisition time of included values ([PRO-0027](./PRO-0027.md)).                                                                        |
| `predicted_for`      | `Option<Instant>`                | The actual sample target time returned by the device if available.                                                                             |
| `sequence_number`    | Selected sequence representation | Present only when `sequence_number_format` is configured; increments per publication within this subscription, wrapping at the selected width. |
| `presence`           | Bitmap                           | One bit per bundle for bundles 1..n indicating whether the bundle is present in this publication. Bundle 0 is always present.                  |
| `samples`            | Encoded values                   | Encoded samples for each present bundle, in order. ([PRO-0025](./PRO-0025.md)).                                                                |

Bundles 1..n should be published on subscription and after subsequent changes to any of the samples in the bundle until an acknowledgement is received that matches the most recent state.

### PublicationAcknowledged

Client-to-server acknowledgment sent over the unreliable channel for a subscription with a configured sequence number format.

| Field             | Type                             | Description                                                                                                                         |
| ----------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `subscription_id` | `u32`                            | Subscription whose publication is acknowledged.                                                                                     |
| `sequence_number` | Selected sequence representation | Sequence encoded using that subscription's configured format; confirms receipt of this exact publication, not earlier publications. |

## Rationale

Acknowledged on-change targets delivery of the latest state, allowing superseded states to be skipped to save bandwidth.
The reliable channel suits consumers that need every published update, in order.
