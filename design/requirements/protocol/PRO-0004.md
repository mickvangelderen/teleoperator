# PRO-0004: The protocol allows evolution

**Tags**: protocol

## Description

- The version is negotiated over the reliable channel.
- No tracking data is transmitted until negotiation succeeds.
- The selected version applies to both channels for the entire session.
- Neither channel needs to carry a protocol version in individual messages.
- A new session requires a new negotiation.
  Versions cannot change mid-session.

## Rationale

A protocol version enables backwards incompatible improvements.
