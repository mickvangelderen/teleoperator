# README.md editing guidance

## When to modify a README.md

Agents are **NOT** permitted to modify `README.md` unless **SPECIFICALLY** requested.

## When to notify about omissions or inconsistencies

In case of absolutely critical omissions or inconsistencies, you may notify the user.
Be conservative in your assessment to avoid unnecessary user distraction.

## Target audience

A readme is primarily meant to be read by humans.
These can be end users, developers, or both.

## What makes a good readme

- A good readme captures high level information necessary to quickly understand what the files under it's scope provide.
- A good readme contains only a careful selection of information that is relevant to its audience.
